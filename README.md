# PointLAM Project Page

Static project page for:

**PointLAM: Local Attentive Mamba for Efficient Point-based 3D Object Detection**

This folder is ready for GitHub Pages. It does not require a build step.

## Files

- `index.html`: page content
- `style.css`: page styles
- `assets/PointLAM_ECCV26.pdf`: linked paper PDF
- `assets/images/*.png`: figures exported from the paper source
- `.nojekyll`: disables Jekyll processing on GitHub Pages

## Deploy With GitHub Pages

Recommended simple path:

1. Create a public GitHub repository, for example `PointLAM`.
2. Push this folder to the repository root.
3. Open repository `Settings -> Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select `main` and `/root`, then save.
6. Wait for GitHub Pages to publish. GitHub says this can take up to 10 minutes.

The final URL will usually be:

```text
https://<github-username>.github.io/PointLAM/
```

If the repository should be private, GitHub Pages availability depends on the account or organization plan.
